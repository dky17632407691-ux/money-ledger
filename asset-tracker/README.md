# 资产净值每日更新服务

记账 App 的「资产」模块数据层：跟踪 A 股、港股、美股和场外基金的持仓，每个交易日自动拉取最新价格与净值，折算成人民币并计算盈亏。

## 目录

```
asset-tracker/
├── config.json        持仓配置（唯一需要你手动维护的文件）
├── tracker.py         抓取行情 → 落库 → 计算 → 打印快照
├── export.py          生成 dashboard.html 看板
├── dashboard.html     可视化看板
└── data/
    ├── portfolio.db   SQLite：持仓、每日价格、汇率、每日快照
    └── latest.json    最新一次快照（供 App / 看板读取）
```

## 怎么用

1. 编辑 `config.json`，把示例持仓换成你自己的：

```json
{ "code": "600519", "name": "贵州茅台", "type": "a", "shares": 100, "avg_cost": 1200.0, "account": "华泰证券" }
```

`type` 取值：`a` = A 股，`hk` = 港股，`us` = 美股，`fund` = 场外基金。
`shares` = 持有份额或股数，`avg_cost` = 摊薄后的每股/每份成本（原币种）。

2. 运行：

```bash
python tracker.py     # 抓取 + 落库 + 打印快照
python export.py      # 刷新看板
```

3. 每个交易日 22:30 自动跑一次（已配置为定时任务）。

## 数据源

| 数据 | 来源 | 说明 |
|---|---|---|
| A 股 / 港股 / 美股 | 腾讯行情 | 一次请求可批量拉取，现价 + 昨收 |
| 场外基金净值 | 天天基金历史净值 | 官方公布口径，含日增长率 |
| 汇率 | 新浪财经 | HKD/CNY、USD/CNY |

## 关键口径

- **市值** = 份额 × 最新价（或净值）× 当日汇率
- **浮动盈亏** = 市值 − 成本，成本按当前汇率折算
- **日盈亏** = 份额 ×（最新价 − 昨收）× 汇率；基金用日增长率反推昨收
- **净值日期** 以接口返回的公布日为准，不取当天日期，避免周末/节假日出现"虚假更新"

## 已知限制

1. **成本汇率**：目前用当日汇率折算，严格应为买入当日汇率。若持有港美股的周期很长，汇率波动会带来误差，后续可在 holdings 表增加 `fx_at_cost` 字段。
2. **分红与拆分**：未处理现金分红、红利再投、基金拆分。这三种情况会改变份额或净值，需要在持仓上补充「分红方式」并做份额调整。
3. **交易日历**：只排除了周末，未排除法定节假日。节假日跑任务会取到上一个交易日的数据，不影响正确性，但界面日期不会变。
4. **申购赎回费**：`avg_cost` 需你自己填含费成本，服务不做费用推算。

## 网页版原型

`webapp/index.html` 是第一版五个功能的可点原型，直接用浏览器打开即可（手机上打开体验更接近 App）。

```bash
python build_web.py    # 把 data/latest.json 注入模板，重新生成 index.html
```

- 五个 Tab 对应 F1 快速记一笔 / F2 收支流水 / F3 月度汇总 / F4 持仓录入 / F5 总资产
- 持仓与行情来自 `data/latest.json`，是真实抓取的数据
- 记账流水是演示数据，存在浏览器 localStorage，刷新不丢；换浏览器或清缓存会重新生成
- 点流水里的任意一笔可以删除；点中间的 ＋ 可以真的记一笔，保存后流水和汇总会同步变化

改界面只需要改 `webapp/template.html`，改完重新跑一次 `build_web.py`。

## 接进 App 的方式

数据层与展示层已经分离：

- App / 小程序只需读 `data/latest.json` 或查 `portfolio.db`
- 定时任务在服务端跑，不依赖 App 是否被打开
- 后续加用户体系时，把 `holdings` 表加上 `user_id`，`config.json` 换成数据库配置即可

## 买卖摊薄 + 资产走势 + 清仓记录（第三轮迭代）
- 新增 holding_trades 表（side/shares/price/fee/amount/realized_profit/is_opening，owner-only RLS×4）；
  holdings 加 closed_at / realized_profit / cost_amount（成本总额，消除单价 4 位舍入的累计误差）。
- 成本口径：cost_amount 为精确账目，cost_price 仅为展示单价（=amount/shares 取 4 位）；
  holdingCost 优先 cost_amount，老数据回退 shares×cost_price。
- 模型（重要）：投资账户余额 = 持仓市值 + 可用资金；可用资金 = initial_balance + 流水 + Σ卖出净额 − Σ买入总额；
  建仓记录（is_opening）不参与现金核算。买入默认扣账户可用资金，可选「从其他账户转入」自动生成转账流水；
  卖出默认留在账户，可选转出。该模型下买卖均不虚增/虚减总资产。
- applyTrade：买入摊薄（含手续费），卖出按单位成本结算已实现盈亏，份额归零写 closed_at；
  removeTrade 删除单笔后按 replayTrades 全量回放重算（支持任意删改）。纯逻辑 node 测试 29 项全过（_t 已删）。
- ensureOpeningTrades：登录后自动为「有份额但无交易记录」的老持仓补建仓记录。
- UI：持仓行加 买入/卖出/记录 三个 mini-btn；openTradeSheet 实时预览摊薄后成本、本次盈亏、卖出后剩余/清仓提示；
  openTradesSheet 交易明细（可删单条，删后重算并重开）。资产页新增清仓记录卡片（默认收起，均价/持有天数/收益率）。
- charts.js 新增 mountMultiArea 多序列走势图；资产页走势升级为 总资产/总负债(虚线)/净资产 三线 + 近1月/3月/半年/1年/全部
  范围切换；概览页新增简版资产走势卡片。state.chartRange / showClosed 为 UI 态。
- 验证：node 纯逻辑测试全过；mock 数据截图核对（余额 387,943 = 市值 279,150 + 可用 108,793 对账一致）；
  390/320px iframe 无溢出。未验证：真实登录后的完整买卖写库链路。
- 用户已开始真实使用（云端有 1 账户、24 分类、2 持仓、1 快照）。

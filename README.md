# 生活记账本 · 独立本地版

纯前端静态应用，无云端后端，不依赖 WorkBuddy。数据只保存在浏览器 `localStorage`。

- **版本**：`202611011200`
- **localStorage 键**：`ledger.standalone.v1`

## 功能

- 日常收支（收入 / 支出 / 转账）
- 持仓资产（A股 / 港股 / 美股），腾讯公开行情
- 今日盈亏（行情时间带完整年份，如 `2026-10-30 16:14`）
- 分类管理（新增分类弹窗正确关闭）
- 账户管理、导入 / 导出 JSON 备份

## 本地打开

ES Module 不能可靠地用 `file://` 双击打开。请用任意静态服务器：

```bash
python -m http.server 8000
```

浏览器打开 http://localhost:8000/

Windows 也可双击 `start.bat`。

## GitHub Pages

仓库根目录即站点根（`index.html`）。资源均为相对路径。推送后在仓库 Settings → Pages 选择 `main` / root。
站点上建议保留根目录空文件 `.nojekyll`。

## 相对原版的简化

- 无登录 / 邀请白名单 / 云同步
- 无货币基金自动申赎、香港退休基金净值同步、场外基金专项
- 无资产日快照走势图、资产日历 K 线回算、财务目标
- 图表仅简单支出条形占比
- 删交易不会联动复杂货基冲销（本版无货基模块）

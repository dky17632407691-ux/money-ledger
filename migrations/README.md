# 数据库变更记录

代码可以通过 Git 同步，数据库结构不能。每次对云端库做 `ALTER TABLE` / `CREATE TABLE` / 新增策略，都在这里留一个 SQL 文件，跟代码一起提交。

**命名**：`YYYYMMDD_简短说明.sql`

**执行方式**：由 WorkBuddy 通过云服务的 SQL 执行能力在云端跑，客户端不执行。

**为什么必须留**：另一台电脑 `git pull` 拿到新代码后，如果库里还没有对应字段，页面会直接查不到数据。有了这个目录，就能一眼看出"这份代码依赖哪些结构变更还没执行"。
